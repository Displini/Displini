# Displini Style Guide

This folder contains design system resources for the Displini project.

## Contents

- **logo/** - All Displini logo variations (SVG format)
- **DESIGN_CHEATSHEET.txt** - Quick reference guide for developers

## Logo Files

All logos are available in:
- Black and white variants
- Icon only
- Text only
- Full logo (icon + text)
- Gradient variations

## Design Cheatsheet

The `DESIGN_CHEATSHEET.txt` file contains:
- Color codes (HSL and Hex)
- Font families and weights
- Spacing values
- Shadow definitions
- Quick reference for CSS variables and Tailwind classes

Use this as a quick reference when developing to ensure consistency with the design system.
